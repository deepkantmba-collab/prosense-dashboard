Layman Translation: What Do These Numbers Mean?
Precision — When we raise an alert, how often is it a real problem? (94.5% = about 19 in 20 alerts are real)
Recall — Of all actual risks, how many do we catch? (82% = we catch about 4 in 5 real risks)
F1 Score — The combined score. Balanced view of both above.

BERT Fear Index — Transformer Architecture (M3 · 5th July + 8th Aug)
📐 Architecture: Encoder-only (unlike GPT = decoder). Bidirectional context.
🔢 Attention: Q·Kᵀ / √d → Softmax → V → new contextual embeddings
🎓 Pre-training: Masked Language Modelling (MLM) — predict masked tokens
🔧 Fine-tuning (planned): Domain-specific — anonymised team feedback, fear labels

Agent Topologies in ProSense (M3 · 2nd Aug)
Hierarchical ✅ Active
Org Agent → Team Agent → Individual (Arjun). Each level aggregates signals from below.
Parallel ✅ Active
4 models run side by side: 2 trained (RF, HGB) + 2 simulated (Delivery, AI Trust).
Loop ✅ Active
Drift detected → retrain → deploy → monitor → back to drift check. Closed feedback loop.
Router 🗺 Phase 2
Agentic RAG router: simple queries → cheap model, complex analysis → full pipeline.
Sequential 🔗 Active
Signal ingestion → feature engineering → model scoring → intervention trigger. Each step depends on the prior one.
Network 🌐 Phase 3
Multi-org learning: patterns across enterprise clients improve shared model without sharing raw data.
Known Challenges & Honest Limitations
An academic panel expects you to own your limitations. Hiding them looks worse than naming them.
RESOLVED — VADER Failure
VADER misclassified workplace language ("I go with the model" → positive). Built custom NLP engine instead. 420 phrases, seed=42, 0 mismatches.
RESOLVED — Class Imbalance
67.1% at-risk vs 32.9% healthy — ratio 2.04:1. Fixed with class_weight="balanced" in both trained models (no SMOTE needed).
RESOLVED — Multicollinearity
psysafe_score ↔ outcome_score r=0.914. VIF analysis run: 34 of 41 features dropped (VIF > 10); 7 clean features used for training.
CRITICAL — Fully Synthetic Data
No real org signals used. Models trained on synthetic patterns may not generalise to real teams. Biggest production risk before any enterprise deployment.
WEAK NLP — WLB, Job Sat, AI Adoption
r=0.305 (WLB), 0.460 (Job Sat), 0.469 (AI Adoption). Language signals too indirect for these pillars. Phrase redesign planned.
DESIGNED — BERT Fear Index Not Yet Trained
Designed and simulated only (planned v0.9.2, 25% canary rollout). Training, SHAP explainability and bias audit are next steps.
BLOCKING — Privacy & GDPR Framework Not Formalised
Cannot deploy to real users until consent framework, data residency, and audit logging are defined. Privacy by Design is a design principle here — not yet an implemented system.
Current status: PoC — demonstrable to design partners and academic panels. Not MVP. Step 12 is complete. Next step to MVP: connect one real (consented) data source + define consent framework + run a real pilot.
